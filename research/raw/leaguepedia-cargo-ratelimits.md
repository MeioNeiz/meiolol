# User:Arbolitoloco/Avoiding cargo ratelimits

This is a user page. It is not maintained actively by wiki staff and may contain inaccuracies.

< [User:Arbolitoloco](https://lol.fandom.com/wiki/User:Arbolitoloco "User:Arbolitoloco")

Fandom added new ratelimits for cargo queries which make it really difficult to query while logged out. If you want to make cargo queries, it's really important to log in with a bot password first and confirm your email address.

## Create a Bot Password

While logged into the wiki, go to [Special:BotPasswords](https://lol.fandom.com/wiki/Special:BotPasswords "Special:BotPasswords"), enter a bot name, and hit create. Then check the ⁨⁨⁨⁨⁨Create, query and delete data through the Cargo extension⁩⁩⁩⁩⁩ box, and hit the create button at the end of the page. If everything worked correctly, you will see a long string of random characters which is your bot password, save this password and the bot name you chose earlier.

## Using your Bot Password to log in

If you use ⁨⁨⁨⁨⁨mwrogue⁩⁩⁩⁩⁩ with Python to make queries, you can find instructions to log in at [Help:Leaguepedia\_API#Python\_Packages](https://lol.fandom.com/wiki/Help:Leaguepedia_API#Python_Packages "Help:Leaguepedia API").

Otherwise, you can look at [mw:API:Login](https://www.mediawiki.org/wiki/API:Login "mw:API:Login").

## Email address confirmation

Make sure you have confirmed your email address at [Special:Preferences#mw-prefsection-reverb](https://lol.fandom.com/wiki/Special:Preferences#mw-prefsection-reverb "Special:Preferences").

## Modified version of ⁨⁨⁨⁨⁨mwcleric⁩⁩⁩⁩⁩ to retry failed queries

If you use Python and mwrogue, it's also a good idea to install a modified version of mwcleric (dependency of mwrogue) to retry failed queries, this way even if you get ratelimited the library will handle everything for you. You can install it by running ⁨⁨⁨⁨⁨

pip uninstall mwcleric
pip install git+https://github.com/arbolitoloco1/mwcleric@empty\_string\_fix
