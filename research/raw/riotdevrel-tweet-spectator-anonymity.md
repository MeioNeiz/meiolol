# Riot Games Developer Relations on X: "Hi everyone, in coordination with the recent League of Legends anonymity additions some changes are coming to the Riot Games API. We will be deactivating the Spectator-V5 API for League of Legends to prevent third party applications from deanonymizing players. However, the new anonymous modes will not have any impact on post-match APIs such as Match-V5 or leaderboards. For a full list of available APIs check out https://t.co/oS9OnQFznE"
