**Bug Description**  
Newly generated (dev-)keys are throwing a HTTP/400 everytime a requests get sends

**Problem Description**  
The key should be valid but it does not get accepted/validated

**Expected Result**  
The expect should work with the correct authentication 

**Actual Result**  
Every request with that key gets dropped/errored. 

**Developer Impact**  
Breaks the new developer experience as well as applications that needed to regenerate their API key
