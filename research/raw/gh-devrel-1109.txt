# #1109 [BUG][LoL][match-v5] ARAM: Mayhem matches return 403 Forbidden
state: closed created: 2025-10-22T22:25:20Z closed: 2025-12-18T19:03:24Z
author: metasrc

**Bug Description**  
When attempting to access match data for ARAM: Mayhem matches, the API returns 403 Forbidden

**Problem Description**  
There was no announcement specifying that this would be the case (like there was for Brawl here: https://x.com/RiotGamesDevRel/status/1922373887599489163) so I am assuming this is a bug.

**Expected Result**  
When I query the match API with ARAM: Mayhem game ids, I should receive a valid response and status 200 OK

**Actual Result**  
When I query the match API with ARAM: Mayhem game ids, I receive an error response with status 403 Forbidden

**Developer Impact**  
This completely blocks the ability for third party developers to build tools and ecosystems to support the new mode.

* Frequency: Every time
* Severity: Makes the API unusable for ARAM: Mayhem
* User emails: We have received several user emails asking if we intend to support ARAM: Mayhem

**Player Impact**  
Players are impacted as they are unable to obtain the information and use the tools they would otherwise be used to having for similar modes, such as ARAM or Arena

* Frequency: Every time
* Severity: Prevents tools and information from being available to the user for this game mode.
* Quantity: Every player seeking tools and information for ARAM: Mayhem from third party sources is affected
* Region: This affects every region

**Repro Steps**  
Query the match API with a game ID from an ARAM: Mayhem game
