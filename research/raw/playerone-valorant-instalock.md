# Valorant Is Going After Instalock Tools — Should Third-Party Apps Be Allowed to Choose Agents Faster Than Humans Can?

**By** [Camille Laurent](https://www.player.one/reporters/camille-laurent) **Published** 09/04/26 EDT

VALORANT’s Agent Select screen is where players choose between Duelists, Initiators, Sentinels and Controllers before a match begins. Riot Games is cracking down on third-party tools that automate or accelerate that selection process. (Image credit: Riot Games) Riot Games

Patch 13.05 is a relatively small update, but one line in it carries much bigger implications for competitive play. Riot says it has begun issuing penalties against players detected using instalock tools, with first offenses resulting in temporary bans and repeated violations escalating toward permanent ones. ([Valorant](https://playvalorant.com/en-us/news/game-updates/valorant-patch-notes-13-05/))

It helps to be precise about what's actually being targeted. A normal instalock happens when a player manually selects an Agent and locks them in before teammates have finished discussing the composition. An instalock tool automates or accelerates Agent selection beyond normal manual input, removing some or all of the human interaction from the process.

Riot isn't banning players for liking one Agent too much. It's targeting software that turns Agent Select into a race humans may not be able to win.

## Human Instalocking and Automated Instalocking Aren't the Same Problem

A player who immediately clicks Reyna every match can be frustrating to play with, but everyone in the lobby has access to the same interface and the same window to act quickly. Automation changes that equation. Third-party software can potentially react to the state of Agent Select and perform actions without waiting on a human to manually find, select, and confirm a character.

That's a fundamentally different advantage than just having quick hands — one player is effectively using software to beat everyone else to a limited team slot.

## Agent Select Is Supposed to Contain a Team Decision

This is where the issue becomes bigger than simple convenience. _Valorant_ isn't built around interchangeable characters — Agents have distinct abilities and play styles, and Riot's third-party policy specifically states that approved products should increase rather than decrease the diversity of in-game decisions, and shouldn't remove decisions from players entirely. ([Riot Games Developer Support](https://support-developer.riotgames.com/hc/en-us/articles/22698769097107-VALORANT))

Agent Select is part of the competitive game. Players may want a Controller, Sentinel, Initiator, or a second Duelist depending on what teammates pick. An automated instalock can make one of those decisions before the conversation even starts — distorting the match before anyone has loaded into the map, without needing to provide aim assistance or reveal enemy positions to do it.

## Where Riot Draws the Line

This isn't an argument against third-party tools broadly. Riot's own developer documentation lists plenty of legitimate use cases — personal match-history tools, tournament utilities, LFG services, and aggregate statistics among them. ([Riot Developer Portal](https://developer.riotgames.com/docs/valorant)) The line Riot draws is around software that provides an immediate competitive advantage or acts on gameplay on the player's behalf. Its broader Terms of Service also prohibit unauthorized scripts, bots, and automation programs that interact with Riot's services. ([Riot Games](https://www.riotgames.com/en/terms-of-service))

That gives the situation a fairly clean test: does the app help a player make a decision, or does the app make the decision for them? A stats tracker sits comfortably on one side of that line. An Agent-selection bot is much harder to defend.

## Banning the Tools Doesn't End Instalocking Itself

It's worth noting what this enforcement doesn't do. Players who manually lock their favorite Agents the instant selection opens aren't going anywhere — Riot's announcement doesn't say instalocking itself breaks the rules, only that instalock tools do. ([Valorant](https://playvalorant.com/en-us/news/game-updates/valorant-patch-notes-13-05/)) So teammates who skip composition discussion for their favorite Duelist will still show up in lobbies. The difference Riot is enforcing is that everyone should be operating under the same human limitations while they do it.

## Agent Select Is Now Part of Riot's Anti-Cheat Boundary

Most conversations about competitive integrity in _Valorant_ focus on what happens after a round starts — aim assistance, wallhacks, scripting, information advantages. Patch 13.05 shows Riot is willing to move that boundary earlier, into the menu screen before a match even begins. If software can automatically secure a popular Agent before another player has a realistic chance to respond, Riot is treating that advantage seriously enough to issue account bans over it.

The question for _Valorant_'s third-party ecosystem is becoming fairly simple: software can help players understand the game, but should it ever be allowed to play even one part of the game for them?
