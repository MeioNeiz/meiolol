# Changes to the LCU API Policy

-   By [**Gene Chorba**](https://www.riotgames.com/en/DevRel/changes-to-the-lcu-api-policy#author)
-   **Jan 24, 2019**

Hey everyone,

We announced in October 2018 that developers could begin to create tools using the LCU API ([https://www.riotgames.com/en/DevRel/league-client-apis-policy-update](https://www.riotgames.com/en/DevRel/league-client-apis-policy-update)). After reviewing some of the applications that have been released and talking to our regional offices we will be making some changes.

-   For the time being we will no longer allow players in Korea to use applications leveraging the League Client API.
-   Before you release an application (or an update to your existing application) that uses the League Client API in any region, you must contact us and let us know.
-   Only endpoints on our approved list are allowed for use by developers

​We have also updated our policies to better reflect these changes [https://developer.riotgames.com/league-client-apis.html](https://developer.riotgames.com/league-client-apis.html)

Gene
