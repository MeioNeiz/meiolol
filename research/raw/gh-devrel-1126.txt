Hi there.
Based on other feedback from the community, the average waiting time is 6-9 months (by now) and steadily increasing. 

Additionally, a production key still has the same limits as a dev key. You need to ask for a rate limit increase on the prod key while or after it has been approved. 

On top of that, I might wanna point out that the matches named on your landing page could be easily pulled within 5 hours, even with a dev key. You might want to check your keys utilization and should try to spread requests more instead of bursting them.

  A few follow-up questions:

  1. **Rate limit increase on dev key** - Is it possible to request a rate limit increase on a dev key while waiting for prod approval? Or is that only for approved prod keys?

  2. **Regarding request spreading** - We've actually just shipped several optimizations:
     - Parallelized match fetching (batches of 5 with retry)
     - Extended match cache to 6h / 2000 entries (cross-user)
     - Reduced match fetch from 20 to 10 per sync
     - Merged duplicate ranked API calls
     - Skip ranked API when only ARAM/normals played

     Our main rate limit issue comes from **Spectator API polling** (game detection every 45s per connected user). We're planning to implement adaptive polling to reduce this. Any other suggestions?
