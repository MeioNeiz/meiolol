# League of Legends on X: "We also wanted to clarify a few questions we saw pop up around streamer mode: Spectating in the League client will continue to function as it does today and will hide information for players that have streamer mode on. Live spectate options on 3rd party sites will be disabled and replaced with enhanced access to replays files via a new endpoint that will be made available in Riot API’s match endpoint. Featured games capabilities will also be disabled. Live games capabilities on 3rd party sites will continue to function but returned results will respect players’ streamer mode settings."
