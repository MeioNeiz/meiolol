# Version 2.5.4

OP.GG·2026.08.27

Spectate is back! TFT is ready for Set 18 🚂

This patch note is based on the Windows version. Some features may not be available on the Mac version.

## New Features

-   Added Augment information to the TFT Comp Details page.
    
-   Added the TFT Synergy Build-Up Recommendation Overlay.
    
-   Added the TFT Season Rewards Overlay.
    

## Improvements

-   Updated TFT comps, items, Augments, and other data for Set 18.
    

## Bug Fixes

-   Fixed an issue that prevented LoL spectating from working.
    
-   Fixed an issue where TFT overlays were not displayed with the new TFT engine.
