# Features available when linking a Riot Account

Bushy

1 year ago Updated

💡

These features are only available after linking a Riot Games account to the OP.GG account. If the Riot Games account has not been linked yet, follow the instructions [here](https://help.op.gg/hc/en-us/articles/31091436118297) to link the account.

# Editing summoner profile

**Where to edit profile by platform**

-   **Web (PC / Mobile)**
    
    Summoner page profile  
    
-   **Mobile App (iOS/Android)**
    
    Upper right of the summoner page  
    
-   **Desktop App**
    
    Settings - Account - Edit Profile  
    

## Registering a favorite team

**Add the League of Legends pro team you support.**

1.  Click the \[Add favorite team\] button on the summoner page.  
    
2.  Select a team to support and click the save button.  
    

## Cover image

1.  Click \[Cover Image\] on the summoner page.  
    
2.  Select the desired cover image and save.  
    

## Personal message

**Leave a personal message to display to users who visit your summoner page.**

🚫

**Notes for using the personal message feature**

-   Links or offensive language are not allowed.
-   If a personal message is reported multiple times, it may be automatically hidden.

# Other features

## Summoner verification URL

✅

**The summoner verification URL is only available on PC Web and Desktop App.**

2.  Click the \[Summoner Verification URL\] button on the summoner page.  
    
3.  The copied URL can be shared in the chat during champion select to verify my stats with team members.  
      
    

## Match notes

Notes can be written and saved for each match, and these notes are **visible only to me**.  

## Quick access to summoner page

Linked summoner accounts are pinned at the top of search history for quick access to the summoner page.
