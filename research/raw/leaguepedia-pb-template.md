### Allowed Values for Roles

Roles are Case-Insensitive (i.e. you can capitalize however you want)

-   T, Top, Toplane, Top Lane
-   J, Jungle, Jg, Jun, Jng
-   M, Mid, Mid Lane, Midlane
-   A, ADC, AD, AD Carry
-   S, Sup, Supp, Support

### What to Enter

-   Bans, picks, roles - straightforward. In champion select order (i.e. before any swaps are made).
-   Team 1, team 2 - make sure that you use our allowed values here, not necessarily the same as Riot's abbreviations
-   Winner - 1 or 2, _**not the name of the winning team!**_ If blue team wins, 1; if red team wins, 2.
-   Scores - the game score within the series, _**not the kill score**_! If it's game 1, it'll be 1-0 or 0-1. If it's game 2 in a series, it'll be either 1-1 or 0-2 or 2-0, etc.

### Notes

-   If teams switched sides, write `|switched_sides=yes`
-   If a team loses a ban, write e.g. `|blue1ban=Loss of Ban`
-   If there is missing data, e.g. from the stream not showing the pick and ban phase, write `|bluepick1=Missing Data`
-   If you aren't entering roles (e.g. you only have access to a pick/ban screen and don't know which champions went to which players) please DO NOT GUESS ROLES!!!! Just write `|noroles=yes` and the template will just display the text _Pick_ instead of the role images.
-   Picks and Bans boxes are can be shown/hidden all at once using `{{[PicksAndBans/Button](https://lol.fandom.com/wiki/Template:PicksAndBans/Button "Template:PicksAndBans/Button")}}`. Please include that template at the top of each page pick/ban page. Optionally, you may also use `{{[PicksAndBans/SectionButton](https://lol.fandom.com/wiki/Template:PicksAndBans/SectionButton "Template:PicksAndBans/SectionButton")}}` to create buttons to show-hide an entire subsection (e.g. a week of a round robin or a round of a bracket) at once, but not the entire page.
-   If the combined score of both teams is greater than 1 (e.g. 2-0 or 1-1), the game is treated as part of a series and collapsed (=space removed) with the one before it, like in the FNC-OMG series [above](https://lol.fandom.com/wiki/Template:PicksAndBansS7#Example). To override this behavior, put `|game=1` in the game that you don't want moved upwards.
-   If you would like to ignore warnings for a game (e.g. there were multiple losses of ban, or the game was blind pick), put `|ignorewarnings=yes`.
