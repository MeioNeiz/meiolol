# The 2018 Hackathon Recap (Riot DevRel, 2019-02-20)

Why: Riot's stated purpose for third-party tools and the categories it chose to reward.

## Assessment

- Evidence: A. Riot DevRel post, Gene Chorba, Feb 20 2019.
- Reasoning: fair. States a philosophy, describes winners, no detailed criteria.
- Interests: Riot; judges from Mobalytics and Blitz (commercial tool companies).
- Weigh: strongest first-party statement that "making players better" tools are wanted;
  2018 era, before Vanguard and the 2022 champ select anonymity rule.

## Findings

- [policy] Riot's stated belief: make data available and empower developers to improve
  the player experience. ^f1
  > At Riot Games we firmly believe in making data available and empowering developers to build tools in order to improve the player experience.
- [policy] Annual in-person hackathon at Riot HQ for four years; 50 developers from 17
  countries in 2018. ^f2
  > this past hackathon we had 50 developers from 17 countries fly in
- [learning] [data] Categories: Visualize (new ways to consume game data) and Teach
  (tools that help players improve). ^f3
  > **Visualize: Present data in a new way, or show us a better way to consume game data**
  > **Teach: Make players better! Provide a tool that will help players improve their skills.**
- [market] [tools] Judging panel included the CEO of Mobalytics and Blitz's editor in
  chief, next to Riot's API product owner: big tool companies were treated as partners. ^f4
  > These projects were to be judged by a panel, made up of **Amine Issa** (CEO of Mobalytics), **Sharon Coone** (Editor in Chief of Blitz Esports), and **Chris Shaw** (Riot API Product Owner).
- [learning] Visualize winner: Champion Changelog, changes to a champion, items and runes
  since a returning player last played it. ^f5
  > Champion Changelog is a League of Legends website that helps returning players get back into the game.
- [tools] Teach winner: AutoGuru, NLP answers to Riot API developer questions. ^f6
  > It uses Natural Language Processing to quickly answer common questions about the API and help developers get back to building tools.
- [learning] Honourable mention Cosmic Insights: in-game overlay with builds and play
  style that react to being ahead or behind. ^f7
  > This project provides real-time in game information to help you play.
- [fun] Honourable mention OmegaLoL: Twitch extension clipping streams from chat emote
  bursts. ^f8
  > Omega LoL is a Twitch Extension that helps capture your stream's most epic moments.
- [policy] (inferred) Cosmic Insights' reactive in-game advice would now sit on the
  wrong side of "drawing conclusions for you during gameplay"
  ([[riot-support-third-party-apps#^f3]]): what DevRel praised in 2018 is not a safe
  template in 2026. Champion Changelog (returning players, patch context) is. ^f9
