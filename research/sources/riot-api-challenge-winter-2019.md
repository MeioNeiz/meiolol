# API Challenge Recap, winter 2018/19 (Riot DevRel, 2019-02-04)

Why: which concrete tools Riot chose to reward and feature.

## Assessment

- Evidence: A. Riot DevRel post by Gene Chorba (Senior Developer Relations), Feb 4 2019.
- Reasoning: fair. One-line descriptions, no reasons for the choices.
- Interests: Riot.
- Weigh: shows 2019 DevRel taste; several winners (friend list tools, champ select
  automation) touch areas Riot later restricted or built itself.

## Findings

- [tools] Usability winner: Dark Binding, per-champion keybinding profiles switched
  automatically. ^f1
  > Dark Binding allows you to define groups of keybindings to which you can assign individual champions.
- [fun] [tools] Usability runner-up: Hextech Friends, lobby invites without friending. ^f2
  > enables you to invite people to your game lobby easily and quickly without having to add them to your friends list
- [fun] Creativity winner: Insert Mission Here, missions for clubs and individuals with
  Club Wars between clubs. ^f3
  > Insert Mission Here creates missions for clubs and individuals. It also features Club Wars a competition between clubs on whose members can complete the most missions
- [fun] [learning] Creativity runner-up: Trophy Hunter, a personal trophy wall of
  challenges aimed at casual players, improvement and teamplay. ^f4
  > The challenges are meant to be fun, help players improve, push them to think outside the box and emphasize teamplay
- [fun] Entertainment winner: API Bravery automates the Ultimate Bravery community mode
  (random champions, spells, runes, items). ^f5
  > API Bravery is an application that automates the Ultimate Bravery community game mode and keeps you honest.
- [fun] Entertainment runner-up: YasuNO, blocks picking Yasuo, a joke tool. ^f6
  > YasuNO is a very simple application that blocks the user from picking Yasuo
- [tools] Shout-outs: voice-controlled champ select, console client, friends list
  export. ^f7
  > League Voice allows you to manage your Champion select with your voice powered by Google Home.
- [fun] (inferred) None of the six winners is a stats site or a win-rate/pick
  recommender: Riot rewarded social, playful and quality-of-life tools. Trophy Hunter
  anticipates Riot's own Challenges system (2022). ^f8
- [fun] (inferred) Hextech Friends and the clubs tools rest on social features Riot later
  reworked itself (Clubs were removed from the client), a replacement risk for social
  tools built on client features. ^f9
