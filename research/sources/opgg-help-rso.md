# OP.GG Help: Features available when linking a Riot Account

Why: what a verified (RSO) link unlocks on the biggest lookup site.

## Assessment

- Evidence: B. OP.GG's own help centre, updated about a year ago.
- Reasoning: fair. A list of features, no rationale.
- Interests: vendor.
- Weigh: trust as what OP.GG offers; no word on what linking hides or protects.

## Findings

- [tools/accounts] Riot link is a layer on an OP.GG account: profile features need both. ^f1
  > These features are only available after linking a Riot Games account to the OP.GG account.
- [tools/accounts] [ux/features] Between games: a linked owner can edit their public summoner page: favourite pro team, cover image, personal message to visitors. ^f2
  > Leave a personal message to display to users who visit your summoner page.
  > Add the League of Legends pro team you support.
- [tools/accounts] [privacy] Personal messages are moderated by reports: links and offensive language banned, auto-hidden after several reports. ^f3
  > If a personal message is reported multiple times, it may be automatically hidden.
- [tools/phase] [tools/accounts] Champ select: a "Summoner Verification URL" (PC web and desktop only) to paste in champ select chat so teammates can check your stats. ^f4
  > The copied URL can be shared in the chat during champion select to verify my stats with team members.
- [tools/accounts] [ux/features] Post game: private per-match notes, visible only to the owner. ^f5
  > Notes can be written and saved for each match, and these notes are visible only to me.
- [tools/accounts] Linked accounts pinned at the top of search history. ^f6
  > Linked summoner accounts are pinned at the top of search history for quick access to the summoner page.
- [tools/accounts] [privacy] Checked, not there: linking offers no hide or private-profile option; the summoner page stays public whatever the owner does (see [[opgg-help-privacy]]). ^f7
- [policy] (inferred) The verification URL is the player choosing to show their own stats to teammates in champ select, the opt-in route that Riot's 12.22 champ select anonymity leaves open; OP.GG only offers it for the linked owner. ^f8
