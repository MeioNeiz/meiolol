# Blitz's own app description (copy on Lutris)

Why: Blitz's first-party words on Riot data use and its relationship with Riot; blitz.gg has no FAQ page now (blitz.gg/faq 404).

## Assessment

- Evidence: C. Vendor text copied onto Lutris; undated, Wine installer "last published 3 years ago", so the text is at least 2023 and likely older (mentions Summoner Names and Platinum+ data).
- Reasoning: weak. Assertions.
- Interests: vendor.
- Weigh: shows how Blitz described its Riot relationship historically; the champ select name feature it describes is now barred by anonymity rules.

## Findings

- [data] [policy] Blitz said it fetched all data from Riot's League API and analysed it itself, using no other third-party stats. ^f1
  > We fetch all our data directly from the Riot's League of Legends API and analyze them ourselves.
- [tools] [ux] Historically showed teammates' names, strengths and ranked win rates on their champion in champ select. ^f2
  > We also grab your teammate's Summoner Names when you enter champion select and automatically display their strengths and ranked win rates on their chosen champion.
- [policy] Blitz claimed it consulted Riot before major features. ^f3
  > We talk with Riot before developing any major features to make sure they are okay with what we are doing!
- [policy] (claim) No bans because it gives no in-game advantage. ^f4
  > You will not get banned for using Blitz since it doesn't give you any advantages in game.
- [policy] (inferred) The teammate-name display (^f2) is a feature that later Riot rules (Solo/Duo champ select anonymity, see [[overwolf-riot-compliance#^f3]]) removed. ^f5
