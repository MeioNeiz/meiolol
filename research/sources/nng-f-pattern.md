# NN/g: F-Shaped Pattern of Reading on the Web (Pernice, 2017)

Why: what scanning means for where words and numbers go, on phones too.

## Assessment

- Evidence: A. Eyetracking studies 2006 and 2017 (heatmaps of 45 and 47 people), page
  last reviewed Aug 2026.
- Reasoning: strong. Corrects misreadings, explains when F happens and why.
- Interests: NN/g sells courses and the report.
- Weigh: about prose pages; tables are scanned in the "spotted" pattern for digits.

## Findings

- [ux] First lines and the first few words on each line get the fixations. The F-Shaped Pattern ^f1
  > First few words on the left of each line of text receive more fixations than subsequent words on the same line.
- [ux] Still true on phones, 11 years later. The F-Shaped Pattern ^f2
  > the F-shaped scanning pattern is alive and well in today's world ... both on desktop and on mobile.
- [ux] Spotted pattern: people skip blocks of text hunting for links, digits or
  distinctive words. Not the Only Scanning Pattern ^f3
  > Spotted pattern consists of skipping big chunks of text and scanning as if looking for something specific
- [ux] Lines starting with the same words get their first words skipped (bypassing). Not the Only Scanning Pattern ^f4
  > Bypassing pattern occurs when people deliberately skip the first words of the line when multiple lines of text in a list start all with the same word(s).
- [ux] Assume scanning; reading everything is rare. Not the Only Scanning Pattern ^f5
  > Assume that most users will be scanning.
- [ux] Headings start with the information-carrying words: the first 2 words should give
  the gist. Antidotes ^f6
  > if users see only the first 2 words, they should still get the gist of the following section.
- [ux] Link text carries information, not "more" or "click here". Antidotes ^f7
  > ensure that links include information-bearing words (instead of generic "go", "click here" or "more").
- [ux] Last antidote: cut unnecessary content. Antidotes ^f8
  > Cut unnecessary content.
- [ux] (inferred) For meio.lol: labels lead with the distinguishing word ("Win rate",
  not "Champion win rate"), and disclosure links name their content, not "more". ^f9
