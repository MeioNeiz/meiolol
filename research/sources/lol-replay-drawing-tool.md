# I hate Paint so I made an in-world drawing tool for replay analysis (r/leagueoflegends, May 2026)

Why: what coaches, casters and content creators lack for explaining games.

## Assessment

- Evidence: B. 4.9k upvotes, 98% upvoted, ~180 comments, May 2026.
- Reasoning: fair. Mostly praise; a few commenters with tool knowledge.
- Interests: author's own demo; commenters say the feature also ships in League
  Broadcast (overlay software), so it may not be novel.
- Weigh: strong signal of goodwill for replay review tooling; not a data need. Drawing
  under champions implies hooking the game, which the 26.20 memory change may break.

## Findings

- [learning] [needs] Coaches and casters explain plays by pausing VODs and drawing in
  Paint; the author built an in-world telestrator. Origin: reviewing games with friends. ^f1
  > I got tired of people having to pause VODs and draw arrows in Paint just to explain a play.
  > Originally made it for reviewing games with friends
- [market] Reception: 4.9k upvotes, 98% upvoted; top comment "Riot, hire this man". ^f2
  > Riot, hire this man
- [needs] Commenters name casters, streamers and coaches as users; one tournament host
  and coach says they wanted it for ages. ^f3
  > This will be an insane feature everyone can use, including casters, streamers, coaches.
  > As someone who personally hosts and casts tournaments, and dabbles a bit in coaching this would be such a nice feature to use!
- [tools] Commenters say the same feature exists in League Broadcast overlay software;
  casters otherwise use Epic Pen or ppInk. ^f4
  > This functionality is baked into an overlay software called League Broadcast.
  > Why wouldnt they just use epic-pen?
- [policy] A commenter quotes Riot's ToS ban on unauthorised programs that read memory,
  arguing drawing on the map implies game interaction. ^f5
  > he's using unauthorized third party software to interact with the game.
- [needs] Requests: fading lines, preset shapes, ally and enemy colours, automatic path
  tracing per champion; a friend group reviewing replays on Discord is a named use. ^f6
  > Say im in discord with the boys and we're reviewing a replay or something.
  > Make a pathing tool that automatically shows a path a champion takes in a set time period.
