# Riot Games Legal Jibber Jabber

Why: notice wording and IP rules for the app's site and binary.

## Assessment

- Evidence: A. Canonical Riot legal page, last updated August 2018 per the page.
- Reasoning: weak. Discretionary.
- Interests: Riot.
- Weigh: two distinct notices exist (this one and the API policy boilerplate); show both to be safe.

## Findings

- [policy] Last updated August 2018. ^f1
  > Last Updated: August 2018
- [policy] Commercial projects allowed only with API Terms/Policies compliance and a valid key granted for the project; revocation means shutdown. ^f2
  > use a currently valid Riot API key that we granted to you specifically for your Project.
  > If we revoke your API key for any reason, you must immediately shut down your Project.
- [policy] No Riot logos/trademarks, and no domains or social accounts using Riot trademarks or names. ^f3
  > You may not register domain names, social media accounts, or similar stuff that uses Riot Games or any of our trademarks, trade names, character names, etc.
- [policy] Fan project notice wording. ^f4
  > [The title of your Project] was created under Riot Games' "Legal Jibber Jabber" policy using assets owned by Riot Games.  Riot Games does not endorse or sponsor this project.
- [policy] Apps using Riot IP need a licence or a valid API key plus policy compliance. ^f5
  > we do not allow any Projects on the Apple Store or Google Play Store unless they have either a written license agreement from us or a valid Riot API key and comply with our API Terms and Policies
- [policy] Checked, not there: nothing on data, ML or model training. ^f6
